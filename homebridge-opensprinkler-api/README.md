# OpenSprinkler artwork

Official artwork downloaded unchanged from https://opensprinkler.com/ on 2026-11-23.

- Square icon: `../header_images/opensprinkler icon.png` (96 × 96 PNG).
  Source: https://opensprinkler.com/wp-content/uploads/2014/09/favicon-96x96.png
- Website logo: `logo.svg` (original SVG, 159 × 40 viewBox).
  Source: https://opensprinkler.com/wp-content/uploads/2014/10/logo.svg

Intended for identifying the OpenSprinkler integration in the HOOBS plugin library and bridge cards, including `homebridge-opensprinkler-api`.

These are existing OpenSprinkler brand assets, not newly designed artwork. No changes, enlargement, or AI-generated content are included.
